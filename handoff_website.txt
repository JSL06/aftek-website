TECHNICAL SPECIFICATIONS

1. Database Schema
   - Articles: id, slug, title_[lang], excerpt_[lang], author_[lang], category_[lang], content_[lang], featured_image, created_at, updated_at
   - Products: id, name, description, specifications, features, images, category, created_at, updated_at
   - Projects: id, title, description, category, images, location, completion_date, created_at, updated_at
   - Tags: id, name, type, created_at
   - Users: id, email, role, created_at

2. File Structure
   - /src/components: Reusable UI components
   - /src/pages: Main page components
   - /src/services: API and business logic
   - /src/contexts: React context providers
   - /src/hooks: Custom React hooks
   - /src/locales: Translation files
   - /public: Static assets and images

3. Dependencies
   - React 18.2.0
   - TypeScript 5.0.4
   - Tailwind CSS 3.3.0
   - Supabase JS 2.38.0
   - React Router 6.8.0
   - Lucide React (icons)
   - Vite (build tool)

4. Environment Variables Needed
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_ANON_KEY
   - VITE_SUPABASE_SERVICE_ROLE_KEY (admin only)
